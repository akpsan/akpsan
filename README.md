## Featured

### 🎯 [WordRush](https://github.com/akpsan/wordrush) · [**Play it →**](https://wordrush.akpsan.workers.dev)
A two-player word game on a shared 8 × 8 grid: grow a chain of words from your last one, and
don't get boxed in first. Play a friend on one device or one of three AI opponents.
The rules were designed with a Python simulation lab. Read
[how 87,300 simulated games shaped them](https://github.com/akpsan/wordrush/blob/main/docs/blog/how-simulations-shaped-wordrush.md).
<br><sub>TypeScript · React · Vite · Python · Cloudflare Workers</sub>

### 🪶 [popover-lite](https://github.com/akpsan/popover-lite) · [![npm](https://img.shields.io/npm/v/popover-lite?style=flat-square&color=cb3837)](https://www.npmjs.com/package/popover-lite)
A ~2 KB popover library built on the native Popover API and CSS Anchor Positioning.
No dependencies, no framework lock-in, and it picks the best placement when your preferred spot doesn't fit.
<br><sub>TypeScript · zero dependencies</sub>

### 🐧 [archsetup](https://github.com/akpsan/archsetup)
Turns a fresh Arch install into a Hyprland desktop with one command. Small, rerunnable modules
(mirrors, hardware detection, zram, firewall, snapshots…) plus symlinked dotfiles.
Personal settings are asked on first run, never committed.
<br><sub>Bash · Hyprland · Waybar</sub>

### 🌍 [LangGuessr](https://github.com/akpsan/langgussr)
A game where you guess the language.
<br><sub>React · TypeScript · Vite</sub>
